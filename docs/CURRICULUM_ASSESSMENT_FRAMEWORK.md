# M01–M20 跨模块能力与实验评价框架

## 1. 评价原则

评价对象不是代码能否运行或答案是否像专家，而是学习者能否解释原理、作出工程选择、实现关键机制、识别失败并提交可复核证据。评价至少覆盖技术正确性、设计质量、实现质量、测试质量、安全质量、运行质量和证据质量。

### 关键能力的递进标准

- 模型基础：M01 解释任务/泛化；M02 推导 Attention；M03 解释 Token/Embedding/Context；M04/M05 将原理转为训练与推理预算。
- 应用工程：M06 建任务契约；M07 控制工具副作用；M08 建证据检索；M09 处理多模态输入和时序。
- Agent 工程：M10 设计受控 Runtime；M11 管理计划和记忆；M12/M13 做协议/能力集成；M14 证明多 Agent 相对单 Agent 的净收益；M15/M16 约束权限和流程。
- 生产与产品：M17 建立统计与观测；M18 建平台控制；M19 证明用户价值和单位经济；M20 集成并答辩。

## 3. 实验难度梯度

| 等级 | 任务类型 | 最低证据 | 评价重点 |
|---|---|---|---|
| L0 概念验证 | 术语辨析、手算、阅读轨迹 | 计算过程、标注图、短解释 | 概念准确、单位/假设 |
| L1 局部实现 | 小函数、Schema、解析、指标计算 | 可运行代码、输入输出、单元测试 | 边界处理、确定性、可读性 |
| L2 工程组件 | RAG/Tool/Agent/Workflow 子系统 | 契约、集成测试、负向测试、失败轨迹 | 接口、安全、幂等、可恢复 |
| L3 系统设计 | 多组件架构、成本/SLO、安全模型 | 架构图、ADR、容量/风险/替代方案 | 权衡、约束、故障域 |
| L4 综合交付 | Capstone 垂直切片和评审 | 冻结版本、端到端证据、演示和残余风险 | 业务结果、系统质量、可复现性 |

## 4. 统一实验评分 Rubric（100 分）

| 维度 | 分值 | 观察证据 |
|---|---:|---|
| 原理与技术正确性 | 15 | 正确解释机制、变量、假设、协议版本和适用边界 |
| 设计与权衡 | 15 | 架构/状态/数据流、替代方案、约束与 ADR |
| 实现与代码质量 | 20 | 可运行实现、接口契约、错误处理、依赖/版本 |
| 测试与失败分析 | 15 | 正向/边界/负向/对抗/故障/恢复用例和结果 |
| 安全与隐私 | 15 | 身份、授权、数据隔离、秘密、审计和人工监督 |
| 可靠性与运行 | 10 | 延迟/吞吐/成本、SLO、监控、降级与恢复 |
| 证据与复现 | 10 | commit、环境、输入、命令、原始输出、未验证项 |
| **总分** | **100** | |

### 硬门槛（不由平均分补偿）
- 关键越权或跨租户数据泄漏测试失败：安全门槛不通过；
- 关键副作用操作无幂等/状态核验策略：相关实验不通过；
- 核心需求无可观察验收条件：项目不得进入 Gate 2；
- 将 Mock、模拟或静态审阅伪称真实服务/生产测试：证据诚信不通过；
- 未披露严重失败、已知风险或未验证项：交付门禁不通过。

## 5. 评价证据等级

| 等级 | 标签 | 定义 | 可支持的结论 |
|---|---|---|---|
| E0 | Designed | 只有设计、伪代码或测试计划 | 证明设计已表达，不证明实现 |
| E1 | Static-reviewed | 静态审阅、Schema/类型/格式检查 | 证明特定静态属性 |
| E2 | Simulated/Mock | 合成数据、mock provider、确定性模拟 | 证明模拟逻辑，不证明外部集成 |
| E3 | Local-tested | 在明确本机环境中执行测试 | 证明该版本在该环境通过对应测试 |
| E4 | Target-env-tested | 在目标环境/真实 sandbox 执行 | 证明目标环境中的特定路径 |
| E5 | Production-observed | 生产流量、监控和事故/运营证据 | 证明观测窗口内的实际运行表现 |

不得跨级推断；E3 不等于 E4，E4 不等于长期 E5。论文、设计图或单次 Demo 不构成 E5。

## 7. 评分一致性和复核

- Rubric 评分项必须引用实际交付物中的证据位置，不得只写“良好/优秀”。
- 10 分制模块作业可映射到统一 100 分 Rubric，但不应机械等比例重复计分。
- 高风险安全项由独立测试证据判定，不因功能演示成功而放行。
- 对开放式架构题允许等价方案；评分看约束、证据和权衡，不要求唯一架构。
- 高风险项目至少双人复核；评分分歧记录争议项、证据和最终裁决。
