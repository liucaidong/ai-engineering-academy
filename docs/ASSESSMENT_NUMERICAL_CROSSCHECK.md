## 2. 重要边界

- 本表只核验明确列出的代表性数值题，不表示所有 100 项作业都属于计算题。
- “数值一致”只证明算式和单位可复算，不证明学习者能够独立理解题目、完成实验或在规定时间内交付。
- 课程中的理论存储、FLOPs、KV 容量和价格均有各自假设；不得将其表述为真实生产测量或当前供应商报价。
- 若讲次案例、作业输入或教师答案发生变化，必须同步更新本表并重新计算。
