# 参考课件审计：llm-courseware

参考项目：[shibaby/llm-courseware](https://shibaby.github.io/llm-courseware)

## 1. 已确认的项目定位
基于上一会话对 README、设计说明、主页面、测试脚本和工作流文件的初步检查，参考项目属于轻量、零依赖、离线优先的单 HTML 交互式科普课件。它不是大型 React 应用，也不是完整的 AI 工程开发平台。

项目明确偏向概念科普与可视化理解，范围上排除了代码教学、API 开发以及模型训练数学原理的系统教学。

> 本文记录的是初步源码审查结论，不构成完整安全审计、性能审计或逐交互行为验收。后续如需复用具体代码，应重新逐项核验许可证、实现细节和测试覆盖。

## 2. 可继承的优点
- 单文件/低依赖形态降低运行门槛；
- 离线可用，适合快速访问和课堂演示；
- 交互可视化有助于建立抽象概念的直觉；
- 轻量测试脚本和静态页面降低部署复杂度；
- 适合作为课程入口和概念预热材料。

## 3. 不应直接继承的限制
- 单页结构不适合承载二十个模块的长期课程治理；
- 科普可视化不能替代工程实现、代码实验和系统评估；
- 离线交互不等于真实模型推理、真实 API 调用或真实 Agent 执行；
- 若缺少版本化内容 schema、来源追踪和学习进度，难以支持持续维护；
- 单一页面不适合后续课程搜索、先修关系、角色管理和多实验运行。

## 4. 本项目的借鉴策略
| 维度 | 借鉴 | 本项目的增强 |
|---|---|---|
| 教学表达 | 直观图示、逐步解释 | 严谨定义、边界与来源 |
| 交互方式 | 参数调整、即时反馈 | 可复现实验、错误案例和评估 |
| 运行门槛 | 轻量、易访问 | 保持前端 MVP 简洁 |
| 内容组织 | 按主题讲解 | 版本化课程、模块、先修关系 |
| 执行可信度 | 教学演示 | 明确 simulation/local/sandbox/provider-backed |
| 质量保障 | 静态检查 | 内容 schema、单测、实验契约和评测集 |

## 5. 后续审计清单
- [ ] 完整检查所有页面交互和状态转换；
- [ ] 核验每个模拟结果是否可能被误解为真实模型行为；
- [ ] 检查键盘可访问性、语义结构和屏幕阅读器支持；
- [ ] 检查移动端布局、性能和离线缓存行为；
- [ ] 检查外部资源、脚本和网络请求；
- [ ] 阅读测试脚本，建立测试覆盖与功能映射；
- [ ] 核验许可证及第三方资源归属；
- [ ] 记录可复用的教学模式，而不是未经审查地复制源代码。

## 6. 结论
应保留原课件作为独立的轻量科普参考，不应将其直接改造成全栈工程平台。AI Engineering Academy 应新建课程内容模型和实验架构，在教学理念上继承其直观性，在工程能力、内容治理、安全和评估方面建立独立体系。
