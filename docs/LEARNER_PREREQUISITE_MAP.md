# M04–M20 学习者先修能力地图

> 状态：内部静态审查补充材料。内容依据课程目录中的模块依赖与学习目标整理；不是学习者试测结果，也不替代先修模块。

## 如何使用

开始模块前，先检查对应的“进入前应能做到”。若不能独立完成，回到列出的模块复习相应讲次，并用自己的例子完成一次复现。先修模块是课程依赖，不要求记住所有细节；重点是能解释核心概念并完成基本任务。

模块页面会显示先修模块链接。本表进一步把模块 ID 转成可自查的能力要求，避免学习者只看到模块编号而不知道需要复习什么。

## 快速自测

进入模块前，尝试不看答案完成以下动作：

1. 用 3–5 句话解释该模块的先修概念，并指出一个常见误用。
2. 手算或复现一个对应先修模块中的核心例题。
3. 画出一个最小数据流/状态流，标注输入、输出和信任边界。
4. 说明当前练习属于概念推导、模拟、mock、本地真实服务还是目标环境验证。

若其中两项以上无法完成，先复习对应先修模块，不建议直接跳过并把后续困难归因于新模块难度。

## 重要限制

- 先修模块依赖来自课程目录；上表的能力描述是对上游模块目标的学习者友好归纳。
- 本表没有证明先修关系在真实学习者中最优，也没有证明每项能力的难度和时间预算。
- M20 的目录依赖覆盖 M01–M19，代表综合项目需要按项目范围调用这些知识，不表示每个 Capstone 都必须实现所有模块的全部技术。
- 形成性学习者试测应记录：学习者是否理解先修要求、是否能自测、复习耗时、补救后是否能够开始目标模块。
