# M02 Claim-to-Source Review — Transformer and Attention

> Review date: 2026-11-10. Scope: 16 lesson-level source occurrences across five lessons.

## Findings and qualifications

- Vaswani et al. (NeurIPS 2017) is the primary source for scaled dot-product attention, multi-head attention, positional encoding and the original encoder-decoder Transformer. Modern decoder-only architectures are variants, not identical copies of the original model.
- Harvard's Annotated Transformer and Dive into Deep Learning are pedagogical implementations/explanations; use the paper for the original design and the current framework API for implementation behavior.
- PyTorch MultiheadAttention documentation is versioned API documentation. Mask shapes, `batch_first`, boolean mask semantics and optimized SDPA behavior must be checked against the installed PyTorch version.
- RoPE encodes position through rotations of Q/K and makes dot products depend on relative displacement; it does not by itself guarantee arbitrary context-length extrapolation.
- Relative-position representations, Pre-LN/Post-LN and RMSNorm claims are tied to the cited papers and their evaluated settings; no universal training-stability guarantee is implied.
- FlashAttention is IO-aware exact attention using tiling to reduce HBM/SRAM data movement and avoid full score-matrix materialization; standard full-attention arithmetic still has a quadratic sequence-length term. FlashAttention-2 performance claims are hardware/workload-specific.
- PagedAttention is a KV-cache memory-management technique used by vLLM; the paper's throughput improvements are not universal guarantees. GQA trades the number of KV heads against MHA/MQA quality and inference-memory behavior.
- The browser Transformer Lab is a fixed-matrix teaching simulation, not a real GPU benchmark or proof that FlashAttention is active.
