## 6. Formula and implementation checks

- **Chunk count:** (N\approx\lceil(D-O)/(C-O)\rceil) is a uniform sliding-window approximation when D, C and O share the same unit. For D=10,000, C=500, O=50, N=23; no overlap gives 20. With O=100, the lesson's alternate formula gives 25; with O=200 it gives 33. Structural boundaries can change actual counts.
- **Unit contract:** the examples assume token counts. LangChain RecursiveCharacterTextSplitter defaults to character length (`len`), not tokens; Unstructured `chunk_by_character`/`max_characters` are also character-based. Token budgets require a tokenizer-aware length function or token splitter. This clarification is now in the lesson, guide and workbook.
- **Vector arithmetic:** for u=(1,0), v=(0.8,0.6), cosine(u,v)=0.8 and dot(u,v)=0.8; for 2v=(1.6,1.2), cosine remains 0.8 while dot becomes 1.6. The example correctly demonstrates scale sensitivity of dot product.
- **RRF arithmetic:** k=60 gives A=1/61+1/65≈0.031778 and B=1/63+1/62≈0.032002; B ranks above A. The teacher guide now records the answer key.
- **ACL and provenance:** parent/child retrieval must inherit ACL; document version, content hash, embedding version and cache key must remain aligned. RAGAS/ARES scores are diagnostic estimates, not proof that a source is true or current.
