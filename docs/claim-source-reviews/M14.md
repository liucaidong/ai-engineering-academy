# M14 Claim-to-Source Review — Multi-Agent Collaboration, State and Evaluation

> Review date: 2026-11-10  
> Scope: 20 lesson-level source occurrences, 19 unique URLs, five lessons.  
> Result: 20/20 source occurrences matched to the specific claims they support. The review also corrected the A2A example to selected A2A v1.0.1 field shapes and tightened trace/evidence semantics.

## Key findings and qualifications

1. **Topology patterns:** Anthropic’s 2024 “Building effective agents” describes routing, parallelization, orchestrator-worker and evaluator-optimizer patterns, but explicitly warns that much of its tooling landscape has changed. Use it for architecture patterns and trade-offs, not current product recommendations.
2. **Multi-agent evidence:** AutoGen, CAMEL and MetaGPT are research/framework examples of configurable conversation, role-play and role-specialized workflows. They do not establish that multiple agents are independent, accurate or always better than one agent.
3. **Vendor internal results:** Anthropic’s 2025 multi-agent research-system article describes parallel subagents and separate context windows, but its performance/cost measurements are internal and task/model-specific. They are not universal benchmark claims.
4. **A2A version pin:** The course now pins A2A v1.0.1. AgentCard requires `supportedInterfaces`; each interface declares `url`, `protocolBinding` and `protocolVersion`. Core bindings are `JSONRPC`, `GRPC` and `HTTP+JSON`. Requests carry `A2A-Version`.
5. **A2A data model:** Task status is nested under `status.state` and uses TaskState enums, including `TASK_STATE_AUTH_REQUIRED`; this state does not grant permission. Message JSON roles are `ROLE_USER`/`ROLE_AGENT`, `messageId` is required, Part has exactly one of `text`/`raw`/`url`/`data`, and Artifact requires `artifactId` and non-empty `parts`.
6. **Internal vs external protocol:** The local Runtime Task/Result schema is an application contract, not A2A wire schema. A2A supports remote agent interoperability; MCP connects models/agents to tools, resources and prompts. They are complementary, not interchangeable.
7. **Shared state:** Chandy–Lamport is a distributed global-snapshot algorithm; it is not CAS, shared-memory consistency or a CRDT. Dynamo demonstrates one highly available design using eventual consistency, vector clocks and application-assisted conflict resolution; its trade-offs are workload-specific.
8. **Evidence independence:** Distinct agent IDs or source URLs do not prove statistical independence. Evidence should be deduplicated by source lineage/provenance, and diversity indicators should be treated as indicators—not proof of independent errors. The example now counts declared `lineage_id` and explicitly states the limitation.
9. **Debate and verification:** Multi-agent debate studies show task-dependent experimental improvements. “On scalable oversight with weak LLMs judging strong LLMs” finds debate advantages over consultancy but mixed results against direct QA depending on task/information asymmetry. Chain-of-Verification is a staged verification method, not a multi-agent debate framework.
10. **Benchmarks:** AgentBench covers multiple interactive environments; SWE-bench evaluates real GitHub issue resolution; τ-bench evaluates tool-agent-user interactions under domain policies and final database state. Results depend on benchmark versions, harnesses and domains; none is a universal production acceptance test.
11. **Tracing and privacy:** OpenAI Agents SDK has built-in trace/task/turn/agent/generation/function/guardrail/handoff spans and custom spans. Artifact spans are custom, not built-in. Generation/function spans may capture sensitive inputs/outputs by default; review `trace_include_sensitive_data`, redaction, export, retention and ZDR availability.
12. **Teaching code limits:** The A2A example validates selected v1.0.1 field shapes only; it does not implement HTTP/JSON-RPC/gRPC, signatures, auth, streaming or full conformance. SharedState uses a process-local lock, not distributed transactions. Evidence lineage is declared metadata, not proof. Wilson intervals and P95 from small synthetic samples are unstable.
