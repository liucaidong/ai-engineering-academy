# M03 Claim-to-Source Review — Tokenization, Embeddings and Context

> Review date: 2026-11-10. Scope: 20 lesson-level source occurrences across five lessons.

## Findings and qualifications

- Sennrich et al. introduced BPE subword units for rare-word handling in neural machine translation; actual tokenization also depends on pre-tokenization, byte/character alphabet, merge ranks and special-token configuration.
- SentencePiece trains subword models from raw sentences and supports BPE/Unigram. Subword regularization samples multiple possible segmentations during training; it is not a universal inference-time behavior. Hugging Face's tokenizer summary is a high-level guide, not a full specification of every tokenizer.
- Word2Vec and GloVe are static word-vector methods; their vectors are not the same as contextual hidden states produced by Transformer layers. GloVe uses global word-word co-occurrence statistics.
- The original Transformer paper supports the embedding/position/attention architecture. The Illustrated Transformer is a secondary visual explanation and is labeled accordingly.
- Lost in the Middle studies position sensitivity in specific long-context tasks/models. LongBench is an ACL 2024 bilingual benchmark with 21 datasets and six task categories. Neither establishes a universal ranking of all current models.
- Gemini 1.5's technical report describes experiments with million-token contexts and retrieval tests up to 10M tokens; these are research results for the reported model family/configurations, not a current API context-window commitment or SLA.
- OpenAI's current token-counting guide describes server-side input counting for Responses API structures. Local tiktoken is useful for supported text encodings but does not account for every multimodal payload or hidden server-side formatting.
- Hugging Face chat templates are model/tokenizer-specific. OpenAI's current text guide documents Responses API message roles and instruction precedence; do not assume all providers use identical serialization or control tokens.
- Lewis et al.'s RAG paper combines parametric generation with a non-parametric dense retriever for knowledge-intensive NLP tasks. A paper result does not guarantee production retrieval quality, permission filtering or citation correctness.
- Llama 3 8B model card is one specific model asset; its tokenizer/configuration and license must not be generalized to later model variants.
