## 3. Supervised and parameter-efficient fine-tuning

| Source | Claim supported | Qualification |
|---|---|---|
| [LoRA](https://arxiv.org/abs/2106.09685) | Frozen base weights plus trainable low-rank matrices; fewer trainable parameters. | Task quality is not guaranteed to match full fine-tuning in every case. |
| [TRL documentation](https://huggingface.co/docs/trl/index) | Official implementation library for SFT, DPO, reward modeling and other post-training methods. | APIs and supported trainers are version-sensitive. |
| [PEFT documentation](https://huggingface.co/docs/peft/index) | Adapter-based tuning, including LoRA, with base-model parameters frozen. | Target modules and API behavior vary by model/library version. |
| [QLoRA](https://arxiv.org/abs/2305.14314) | Frozen 4-bit base weights, gradient propagation to LoRA adapters, NF4, double quantization and paged optimizers. | The reported 65B-on-48GB result is a specific setup, not a general hardware guarantee. |

## 4. Preference alignment

| Source | Claim supported | Qualification |
|---|---|---|
| [InstructGPT](https://arxiv.org/abs/2203.02155) | Demonstrations for SFT followed by human preference rankings and RLHF. | The paper notes remaining errors and evaluates a specific prompt distribution. |
| [PPO](https://arxiv.org/pdf/1707.06347) | Clipped probability-ratio surrogate objective and policy-update constraint intuition. | Original experiments are general RL tasks; LLM RLHF is a later application. |
| [DPO](https://arxiv.org/abs/2305.18290) | Direct preference classification objective with implicit reward parameterization, avoiding a separate reward-model/RL loop. | Original results are task- and benchmark-specific; no universal superiority claim. |
| [DPO vs PPO comprehensive study](https://proceedings.mlr.press/v235/xu24h.html) | 2024 ICML empirical/theoretical comparison; reports PPO outperforming in the study's evaluated RLHF testbeds. | Evidence against a blanket DPO-superiority claim, not proof that PPO always wins. |
| [Constitutional AI](https://www.anthropic.com/research/constitutional-ai-harmlessness-from-ai-feedback) | Principle-guided self-critique/revision and AI-feedback reinforcement learning (RLAIF). | Empirical claims are scoped to the paper's tested models and evaluation methods. |

The most important scope boundaries are already present in the teaching content: Chinchilla scaling is not universal; Mixtral active parameters are distinct from resident weights; QLoRA memory claims are not hardware guarantees; PPO/DPO comparisons are benchmark-dependent; and HELM/model cards/datasheets do not constitute complete certification.
