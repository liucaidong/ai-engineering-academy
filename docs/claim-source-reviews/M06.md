## 6. Calculation and implementation checks

- `examples/m06/05_prompt_eval_metrics.py` implements the Wilson score interval with the standard center, denominator and margin terms. For 50 successes out of 100 with (z=1.96), the interval is approximately [0.404, 0.596].
- The order-bias diagnostic compares the mean score for candidate A when presented first versus second on the same paired examples. It is an illustrative diagnostic, not a complete statistical test or an implementation of bootstrap.
- The lesson and workbook now state that paired comparisons must resample the same task/example pairs and report the paired difference interval. A and B arms must not be independently resampled.
- The three-layer validation model remains correct: JSON parse → schema validation → semantic/business validation → authorization. Constrained generation can improve format compliance but cannot establish truth or permission.
- Prompt injection mitigations remain defense-in-depth: untrusted-source labeling and structure help the model, but tool allowlists, server-side authorization, least privilege and side-effect approval enforce the actual boundary.
