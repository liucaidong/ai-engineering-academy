# AI Engineering Academy 首轮学习者试测招募工具包

> 状态：招募材料已准备；尚无参与者报名或确认。
> 目标样本：8 人（A 组 2 人、B 组 3 人、C 组 3 人）；最低有效样本为 6 人。
> 用途：形成性课程质量验证，不是招聘、升学、资格认证或统计显著性研究。

## 1. 招募画像

| 组别 | 人数 | 经验画像 | 选择目的 |
|---|---:|---|---|
| A | 2 | 基本计算机使用能力；没有系统 AI/ML 工程经验 | 检验零基础学习者能否理解入门路径、数学桥接和课程术语 |
| B | 3 | 有软件开发、API、数据库或测试经验；LLM/Agent 实战有限 | 检验软件工程师能否迁移到 RAG、Agent、MCP 和评测工程 |
| C | 3 | 做过 LLM 应用、RAG 或 Agent 项目；生产工程经验不完整 | 检验进阶内容、工程权衡和 Capstone Gate 的可操作性 |

分组按实际经历而非自我称号确定。避免 8 人全部来自同一团队、同一岗位或同一经验层级。首轮不追求年龄、性别、学校或雇主等人口统计平衡；除非确有研究必要，不收集这些信息。

## 2. 招募文案（可直接复制）

**标题：** 邀请参加 AI Engineering Academy 课程试学与反馈

我们正在对 AI Engineering Academy 的 M01–M20 课程进行首轮形成性试测，希望邀请不同经验层级的学习者实际使用课程材料，并反馈讲解、先修要求、实验、正式作业和 Capstone 任务是否清晰、可完成。

参与者将完成一份入门诊断、若干指定讲次与作业，并记录实际学习时间、遇到的阻塞和需要的帮助。部分有相关经验的参与者还会进行 M20 Capstone Gate 0–4 演练。

这不是考试、招聘、升学或资格认证；不会按结果淘汰参与者。参与完全自愿，可以跳过任务或随时退出。试测默认不录制屏幕、音频或视频，也不要求购买 API、GPU 或付费服务。请勿提交真实客户资料、商业机密、密码、API Key 或其他凭证。

我们希望覆盖三类经验：没有系统 AI/ML 工程经验；有软件/API/数据库经验但 LLM/Agent 实战有限；做过 LLM/RAG/Agent 项目。试测安排、记录范围、数据保存期限和退出方式会在参与前说明，并在取得知情同意后开始。

如愿意参加，请回复简要说明你更接近哪类经验，以及可参加的时间段。无需提供身份证、雇主信息、客户资料或其他无关个人信息。

## 3. 报名筛选问题

只记录完成分层和安排所需的信息。不要要求提交身份证明、简历、雇主名称、客户项目材料或真实账号。

1. 你是否有软件开发经验？选择：无 / 个人练习 / 工作项目。
2. 你是否使用过 Python、TypeScript/JavaScript 或其他编程语言？请写语言和大致经验区间。
3. 你是否理解 HTTP、API、JSON、数据库等基础概念？选择：不了解 / 接触过 / 能独立使用。
4. 你是否学习或使用过机器学习、神经网络、LLM？选择：没有 / 理论学习 / 做过小练习 / 做过项目。
5. 你是否做过 Prompt、Tool Calling、RAG、Agent、MCP 中的任一项？可多选并简述，不要求展示代码或项目机密。
6. 你对矩阵乘法、概率、向量和基本统计的熟悉程度如何？选择：不熟悉 / 学过但不常用 / 能独立计算。
7. 你是否可以使用普通浏览器和本地文档？是否存在会影响参与的无障碍或设备限制？可自愿说明。
8. 你能否参加至少两次试测时段？如不能，也可报名单次任务观察。

筛选时只把上述回答用于经验分组、任务分配和环境准备。若收集联系信息，应与匿名学习数据分开保存。

## 4. 分层规则

- A 组：没有系统 AI/ML 工程经验；若编程经验较强，记录为 A+，不要把其表现等同于完全零基础。
- B 组：具备软件/API/数据库/测试基础，但没有独立交付过完整 RAG/Agent 系统。
- C 组：至少做过一个 LLM 应用、RAG 或 Agent 项目；仍需检查其是否具备权限、安全、评测和可靠性工程经验。
- 经验边界模糊时，优先按入门诊断结果和可复现经历分组，不按自我评价单独决定。
- 不因参与者知识薄弱而拒绝 A 组；学习者遇到困难本身就是课程验证证据。

## 6. 数据最小化与安全

- 联系方式只用于安排试测，单独保存并限制访问；课程行为数据使用匿名 ID。
- 不收集身份证号、住址、账户信息、健康/宗教/政治等敏感信息，不要求提供工作单位或客户名称。
- 参与者不得把真实客户数据、商业秘密、源代码机密、密码、API Key、访问令牌或个人敏感信息带入试测。
- 原始笔记只记录完成分析所需的行为、时间、阻塞、任务结果和匿名工件引用。
- 录制不是默认项；若另行录制，应有独立同意、访问名单、保留期限和删除方式。
- 对外报告使用聚合统计或经单独授权的匿名引述；小样本中即使删除姓名也可能通过项目细节识别个人，需做再识别风险检查。
- 不得将参与者作业用于公开展示、模型训练、招聘评估或宣传，除非另行取得明确授权且符合适用规则。
