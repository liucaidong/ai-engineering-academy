# M01–M20 计算题与定量示例复核报告

> 核验日期：2026-11-10。范围：20 份实验工作簿中的显式计算任务/数值示例、M04–M20 Python 示例的公式实现与测试断言。所有金额均为教学假设；所有合成数据结果仅验证计算逻辑，不代表真实模型、生产服务或供应商账单。

## 1. 核验方法与边界

- 对照工作簿中的输入、公式、变量、单位和预期解释，独立重算关键数值。
- 检查 Python 实现中的公式、分母、边界条件、数值类型和单位；用测试断言复核可执行示例。
- 明确区分精确算术、近似估算、统计估计、容量上界和业务策略阈值。
- M01、M12 没有独立的数值算题；M20 的 75/100 是课程教学门槛，不是统计公式或行业标准。
- M04–M20 的 17 组 Python 示例测试本轮共 88 项通过；本报告不把测试通过外推为真实服务/生产验收。
