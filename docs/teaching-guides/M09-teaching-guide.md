# M09 教师教学指南与作业参考解答

> 版本：0.20.0 · 适用模块：M09 多模态 AI  
> 用于教师备课、助教批改和学生复习；参考解答不是唯一可接受答案。

## 使用方式

- 建议每讲 75–90 分钟；先从真实案例提出问题，再推导机制，最后审阅工程证据。
- 课前让学生写下假设；课堂结束前提交公式、架构图、状态图、测试记录或决策日志。
- **教学主线：** 跨模态系统必须分别处理编码、对齐、时间同步、模态缺失、模态级评测、隐私与资源成本。
- 评分先检查边界、假设、单位、失败路径和证据，再检查表达完整性。

## 模块先修与教学准备

- **先修知识：** 线性代数、图像 patch、概率噪声过程、音频采样与时间戳
- **教师准备：** 准备一个最小正例、一个失败案例和一份可审计输出；区分模型推断、宿主控制、业务规则与外部系统状态。
- **贯穿案例：** 多模态 AI 的作业均要求说明输入、状态、权限、输出、成本和异常处理。

## 第一讲：多模态架构与表示对齐

### 课前准备

- 复习：线性代数、图像 patch、概率噪声过程、音频采样与时间戳
- 预读主题：多模态系统的基本结构、Early Fusion、Late Fusion 与 Cross-Attention、表示对齐与训练数据、模态缺失与鲁棒性、复现练习：设计会议助手的跨模态时间线。
- 准备一个成功路径和一个失败路径，要求学生比较其状态、权限和恢复差异。

### 教学路径与关键讲解

1. **概念建立：** 讲解 多模态系统的基本结构、Early Fusion、Late Fusion 与 Cross-Attention、表示对齐与训练数据，先定义对象、边界和数据流。
2. **工程深化：** 以 模态缺失与鲁棒性 为切入点讨论异常、权限、成本或可维护性，并指出由哪个可信组件执行控制。
3. **实践复现：** 复现练习：设计会议助手的跨模态时间线。先独立推导，再对照参考解答检查假设与边界。
4. **证据要求：** 提交物包含输入/假设、处理步骤、结果、失败路径、版本和未验证项。

### 学习检查点（含教师提示）

- **对象与边界：** 能否说明参与方、状态、数据和责任归属？若把模型建议写成已执行状态，要求重画控制流。
- **机制与权衡：** 能否解释核心算法/协议及其成本？要求给出至少一个替代方案。
- **验证与失败：** 是否定义异常、权限拒绝、超时、恢复或人工接管？没有负向测试的设计不完整。

### 课后复习

- 不看讲义重画本讲数据流/状态图，并逐项标记可信边界。
- 为一个失败案例写出根因、检测信号、恢复动作和防复发测试。
- 将结论转化为一条可自动检查的验收条件。

### 正式作业参考解答

**原始作业：** 为会议助手设计音频、视频帧和文本融合架构，比较 early fusion、late fusion 与 cross-attention，并说明模态缺失策略。

**参考解答与推理：** 会议助手可采用音频 ASR、视频抽帧、说话人/时间戳与文本编码后做 late fusion；细粒度跨模态交互可在投影后用 cross-attention。Early fusion 交互强但同步和算力成本高；late fusion 模块化、缺模态容错较好。所有片段用统一会议时钟和时间区间对齐。

**原始 Rubric 对照（满分 10 分）：**

- **数据流（4 分）：** 说明各模态编码、投影和融合路径。要求提交物中有直接证据支持该项结论。

- **架构比较（3 分）：** 比较交互能力、计算和时序成本。要求提交物中有直接证据支持该项结论。

- **鲁棒性（3 分）：** 覆盖模态缺失、噪声和时间同步。要求提交物中有直接证据支持该项结论。

**常见错误与纠正：**

- 把模态拼接等同于对齐；忽略时间戳；把 patch 数线性误当注意力成本；不报告 WER/隐私；将理论带宽当实测。
- 只写术语、不展示推导或数据来源；要求补充中间步骤和可复核依据。
- 把设计、模拟和真实执行混为一谈；要求显式标注验证等级。

### 正式作业参考解答

**原始作业：** 计算 384×384 输入在 patch=16 和 patch=8 时的 patch 数、含 CLS 的序列长度，并比较标准注意力矩阵规模比。

**参考解答与推理：** 384/16=24，每边24个 patch，合计576；加 CLS 为577。384/8=48，每边48个，合计2304；加 CLS 为2305。序列长度约4倍，标准全注意力矩阵约16倍。Patch 变小保留细节，但显存、延迟和数据需求上升。

### 正式作业参考解答

**原始作业：** 解释 DDPM 的 x_t 构造式和噪声预测损失，并分析 CFG scale 过高时可能出现的两类质量问题。
