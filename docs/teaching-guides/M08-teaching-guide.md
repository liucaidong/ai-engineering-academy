# M08 教师教学指南与作业参考解答

> 版本：0.20.0 · 适用模块：M08 检索增强生成 RAG  
> 用于教师备课、助教批改和学生复习；参考解答不是唯一可接受答案。

## 使用方式

- 建议每讲 75–90 分钟；先从真实案例提出问题，再推导机制，最后审阅工程证据。
- 课前让学生写下假设；课堂结束前提交公式、架构图、状态图、测试记录或决策日志。
- **教学主线：** RAG 是离线摄取与在线检索/生成的双流水线；证据、版本、ACL、引用定位和无答案策略必须成为一等契约。
- 评分先检查边界、假设、单位、失败路径和证据，再检查表达完整性。

## 模块先修与教学准备

- **先修知识：** 概率/向量基础、文档解析、数据库索引、访问控制与评测指标
- **教师准备：** 准备一个最小正例、一个失败案例和一份可审计输出；区分模型推断、宿主控制、业务规则与外部系统状态。
- **贯穿案例：** 检索增强生成 RAG 的作业均要求说明输入、状态、权限、输出、成本和异常处理。

## 第一讲：RAG 系统边界与端到端数据流

### 课前准备

- 复习：概率/向量基础、文档解析、数据库索引、访问控制与评测指标
- 预读主题：为什么需要 RAG、离线与在线两条流水线、证据与引用契约、无答案与权限边界、复现练习：追踪一次可引用 RAG 请求。
- 准备一个成功路径和一个失败路径，要求学生比较其状态、权限和恢复差异。

### 教学路径与关键讲解

1. **概念建立：** 讲解 为什么需要 RAG、离线与在线两条流水线、证据与引用契约，先定义对象、边界和数据流。
2. **工程深化：** 以 无答案与权限边界 为切入点讨论异常、权限、成本或可维护性，并指出由哪个可信组件执行控制。
3. **实践复现：** 复现练习：追踪一次可引用 RAG 请求。先独立推导，再对照参考解答检查假设与边界。
4. **证据要求：** 提交物包含输入/假设、处理步骤、结果、失败路径、版本和未验证项。

### 学习检查点（含教师提示）

- **对象与边界：** 能否说明参与方、状态、数据和责任归属？若把模型建议写成已执行状态，要求重画控制流。
- **机制与权衡：** 能否解释核心算法/协议及其成本？要求给出至少一个替代方案。
- **验证与失败：** 是否定义异常、权限拒绝、超时、恢复或人工接管？没有负向测试的设计不完整。

### 课后复习

- 不看讲义重画本讲数据流/状态图，并逐项标记可信边界。
- 为一个失败案例写出根因、检测信号、恢复动作和防复发测试。
- 将结论转化为一条可自动检查的验收条件。

### 正式作业参考解答

**原始作业：** 为企业知识助手画出离线/在线 RAG 数据流，定义 chunk 元数据、引用定位、ACL 过滤和无答案策略。

**参考解答与推理：** 离线链路：source registry→权限/许可检查→解析规范化→chunk+metadata→embedding→稀疏/向量索引→版本快照。在线链路：身份认证→查询改写→ACL 过滤→多路召回→融合/重排→上下文预算→生成→引用验证。chunk 保留 document/version/page/offset/ACL；无证据或无权访问时 abstain。

**原始 Rubric 对照（满分 10 分）：**

- **流水线（3 分）：** 离线摄取与在线检索阶段完整。要求提交物中有直接证据支持该项结论。

- **证据追溯（3 分）：** chunk 和 citation 可回到原文版本。要求提交物中有直接证据支持该项结论。

- **安全边界（4 分）：** 检索前/查询时执行 ACL 并定义无答案。要求提交物中有直接证据支持该项结论。

**常见错误与纠正：**

- 只看向量相似度；忽略 ACL 和版本；把召回率与答案正确率混为一谈；引用无法定位原文；缓存跨租户复用。
- 只写术语、不展示推导或数据来源；要求补充中间步骤和可复核依据。
- 把设计、模拟和真实执行混为一谈；要求显式标注验证等级。

## 第二讲：文档摄取、解析与 Chunking

### 正式作业参考解答

**原始作业：** 对 10,000 token 文档比较 chunk=500/overlap=50 与无 overlap 的 chunk 数，并设计保留标题、表格、ACL 和来源定位的解析策略。

**参考解答与推理：** 10,000 token、chunk=500、overlap=50，步长450；按覆盖长度估算 chunk 数约 ceil((10000-50)/(500-50))=23。无 overlap 时约20。切分按标题/段落/表格结构优先；metadata 保留来源、版本、权限、页码/offset、时间与解析器版本。

**原始 Rubric 对照（满分 10 分）：**

- **计算（3 分）：** 正确得到约 23 与 20 个 chunk 的估算。要求提交物中有直接证据支持该项结论。

- **切分取舍（3 分）：** 说明粒度、语义完整和冗余成本。要求提交物中有直接证据支持该项结论。

- **元数据（4 分）：** 保留版本、权限、来源和结构定位。要求提交物中有直接证据支持该项结论。

**常见错误与纠正：**

- 只看向量相似度；忽略 ACL 和版本；把召回率与答案正确率混为一谈；引用无法定位原文；缓存跨租户复用。
- 只写术语、不展示推导或数据来源；要求补充中间步骤和可复核依据。
- 把设计、模拟和真实执行混为一谈；要求显式标注验证等级。

### 正式作业参考解答

**原始作业：** 给定 u=(1,0)、v=(0.8,0.6)、2v=(1.6,1.2)，计算 cosine 和 dot product，并比较 HNSW 与 IVF 的主要调参变量。

**参考解答与推理：** cosine(u,v)=0.8/(1×1)=0.8；dot(u,v)=0.8。对2v，cosine仍为0.8，dot=1.6，说明点积受向量范数影响。HNSW 通过多层近邻图导航，调 M、efConstruction、efSearch；IVF 先聚类分桶，调 nlist/nprobe。用 exact search 对照 ANN Recall@k 和延迟。

**原始 Rubric 对照（满分 10 分）：**

- **相似度计算（3 分）：** 正确算出 cosine=0.8 且 dot 随缩放变化。要求提交物中有直接证据支持该项结论。

- **索引机制（4 分）：** 说明 HNSW 图导航与 IVF 分桶。要求提交物中有直接证据支持该项结论。

- **评测（3 分）：** 提出 Recall@k、延迟和过滤安全验证。要求提交物中有直接证据支持该项结论。

### 正式作业参考解答

**原始作业：** 给定文档在 BM25 和 dense 两路的排名，使用 k=60 计算 RRF 分数，并设计 top-50 召回、rerank top-5 的延迟与质量评测。

**参考解答与推理：** RRF(d)=Σ_i 1/(k+rank_i(d))，k=60。把两路排名逐文档代入并相加，按分数降序得到融合列表；只出现在一路的文档，另一路贡献为0。top-50 召回、rerank top-5 需测 Recall@50、nDCG@5、MRR、端到端延迟和 query rewrite 消融。

**原始 Rubric 对照（满分 10 分）：**

- **RRF 计算（3 分）：** 公式和排名代入正确。要求提交物中有直接证据支持该项结论。

- **架构取舍（3 分）：** 说明稀疏/稠密互补及 rerank 成本。要求提交物中有直接证据支持该项结论。
