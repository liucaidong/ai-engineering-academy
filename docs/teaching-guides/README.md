# 教师教学指南索引

本目录存放旗舰课程的配套教师指南与正式作业参考解答。指南用于帮助教师备课、助教批改和学生复习，不替代课程内讲义、作业要求或正式评分 Rubric。

## 每份指南的固定结构

1. 课前准备与先修知识；
2. 教学路径和关键公式/计算的推导；
3. 学习检查点及教师提示；
4. 课后复习任务；
5. 本模块五项正式作业的参考解答；
6. 与原始 Rubric 对齐的评分说明；
7. 常见错误和纠正重点。

## 教学使用约定

- 参考解答解释一种严谨、可复核的解题路径，不是唯一标准答案。
- 数值结果应连同单位、假设、边界和不确定性一起评分。
- 设计方案必须区分已实现、已测试、模拟和未验证。
- 对安全、权限和外部副作用，不能用 Prompt 声明替代服务端强制控制。
- 教师可根据班级基础调整时长，但不应删去证据要求和失败案例讨论。
